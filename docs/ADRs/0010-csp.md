# ADR-0010: CSP: hashes for scripts and style elements, `unsafe-inline` for style attributes only

- Status: Accepted
- Date: 2026-11-12

## Context

NFR-04 requires a strict CSP meta policy. Astro generates hashes for its inline scripts and styles. The islands use a few inline `style` attributes for layout nudges.

## Decision

Enable `security.csp`: `default-src 'self'`, `connect-src 'self'`, `frame-src https://www.youtube-nocookie.com`, `object-src 'none'`, scripts only by hash and `'self'`. Style elements are hash-only; inline style attributes are allowed through `style-src-attr 'unsafe-inline'`. No `unsafe-eval`; `'wasm-unsafe-eval'` for Pagefind.

## Consequences and requirement impact

Inline style attributes cannot execute script, so the residual risk is low. They could be replaced by classes later. A Playwright check fails tests on any console CSP violation.
